# 모멘텀 (Momentum) — 함께 공부하는 자격시험 학습 웹앱

**▶ 바로 체험하기: https://skyang0817-hue.github.io/momentum-study-app/?demo**
(로그인 없이 예시 학습 기록으로 열리는 체험 모드입니다. 실제 서비스 서버와 연결되지 않으며, 오른쪽 위 **⋯** 버튼을 누르면 과목(CPA 2차·1차 재무관리, 네트워크관리사)을 바꿀 수 있습니다.)

여러 명이 각자 계정으로 자격시험을 공부하고, 관리자가 진도를 함께 보는 **다과목 학습 웹앱**입니다.
과목을 '과목 팩'으로 분리해 문제·단원·모의고사 형식만 추가하면 새 과목을 붙일 수 있게 설계했습니다.

| 과목 | 특징 |
|---|---|
| CPA 2차 재무관리 | 회독마다 숫자가 바뀌는 서술형 계산 문제, 약술형, 개념 사전 |
| CPA 1차 재무관리 | 숫자가 바뀌는 5지선다 계산형·이론형 |
| 네트워크관리사 2급 필기 | 객관식·O/X, 명령어 출력 해석형 |

운영 중인 서비스에는 정보처리기사 실기 과목도 있지만, 외부 출처 문항이라 이 공개본에서는 뺐습니다.

상경계열 학생이 2학기 수업과 병행하며 생성형 AI(Claude Code)와 함께 기획·개발했고, 2026년 10월 말부터 지인들과 시험 운영했습니다.

> 이 저장소는 포트폴리오 공개용 사본입니다. 실제 서비스의 접속 정보(Supabase 주소·키)는 비워 두었고,
> 외부 출처 문제(정보처리기사 문항, 2026년 CPA 기출 원문 기반 문항)는 저작권을 고려해 제외했습니다.

## 만든 이유

- 계산 문제는 숫자를 외우면 회독 효과가 떨어집니다 → **회독마다 숫자가 바뀌고 자동 채점**되게 만들었습니다.
- 혼자 공부하면 꾸준함이 무너집니다 → **출석 인증·접속 현황·관리자 진도 확인**으로 함께 공부하는 구조를 만들었습니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 숫자 변형 문제 | 문제마다 숫자 생성기와 정답 계산 함수를 두어, 2회독부터 새 숫자로 출제되고 자동 채점 |
| 간격 반복 복습 | 1·3·7·14·30·60일 간격으로 복습 일정 자동 구성 |
| 모의고사 | 과목별 시험 형식으로 구성 (CPA 2차 재무관리: 7문제·120분), 회차별 기록 |
| 오답 분석 | 오답 이유를 통계로 분석 (유료 AI API 없이) |
| 출석 인증 | 정해진 시간대에 카메라 촬영, 서버 시각으로 판정 |
| 관리자 화면 | 사용자별 회독·단원 정답률·문제별 현황 |
| 과목 팩 | 과목별 문제·단원·모의고사 형식을 분리, 계정마다 쓸 수 있는 과목 지정 |
| PWA·알림 | 폰 홈 화면 설치, 웹 푸시 알림 |

## 기술 구성

- **프런트엔드:** 빌드 도구 없는 순수 JavaScript·HTML·CSS
- **백엔드:** Supabase (인증, PostgreSQL, 실시간 접속 현황, 사진 저장소)
- **배포:** Cloudflare Workers 정적 자산 + 푸시 전달용 워커 (`worker.js`)
- **비용:** Supabase·Cloudflare 무료 요금제로 운영할 수 있게 구성했습니다. 문제 해설용 AI API는 비용 때문에 의도적으로 쓰지 않았습니다.

## 설계에서 신경 쓴 점

- **권한:** 행 수준 보안(RLS)으로 일반 사용자는 자기 기록만, 관리자만 전체 기록을 봅니다. 사용자가 스스로 관리자가 되지 못하게 막았습니다 (`supabase/schema.sql`).
- **보안 헤더:** CSP로 외부·인라인 스크립트를 차단하고, 연결 대상을 이 사이트와 Supabase로 제한했습니다 (`_headers`).
- **공개 키만 클라이언트에:** 브라우저에는 공개용 키만 두고, 비밀 키는 서버 쪽 표에만 둡니다.
- **측정 기준:** 공부 시간·접속 현황처럼 숫자로 보이는 기능은 측정 규칙을 먼저 정한 뒤 만들었습니다.

## 검증

- `tools/test.html` + `tools/verify_defaults.py`: 문제의 기본 숫자 정답을 독립 계산과 대조
- `tools/alt_check.py`: 변형 숫자 세트를 다른 풀이 방법으로 교차검증
- `tools/e2e.html`, `tools/e2e_sb.html`: 로컬 모드와 가짜 Supabase로 채점·기록·로그인·권한 동작 점검 (localhost에서만 실행)

## 문제 출처

모든 문제는 공개 기출의 **출제 경향(단원 비중·빈출 주제·물음 구성)만 참고해 새로 만든** 문제이며, 기출이나 시판 문제집의 원문을 옮기지 않았습니다.

- CPA 재무관리(1차·2차): 금융감독원 공개 기출 참고
- 네트워크관리사 2급: 공개된 CBT 기출의 과목 배분·빈출 주제 참고

## 실행 방법

### 1. 내 PC에서 바로 써 보기 (로컬 모드)

`config.js`를 비워 둔 채로 폴더에서 아래를 실행하고 http://127.0.0.1:8765 를 엽니다.

```
python -m http.server 8765
```

기록은 이 브라우저에만 저장됩니다.

### 2. Supabase 연결 (계정별 저장)

1. https://supabase.com 에서 새 프로젝트를 만듭니다 (무료).
2. **SQL Editor**에 `supabase/schema.sql` 내용을 붙여 넣고 **Run**. 출석 인증용 사진 저장소(`attendance`)도 함께 만들어지며, 기능이 추가될 때 다시 실행해도 안전합니다.
3. **Authentication → Sign In / Providers**에서 Email을 켜고, **Allow new users to sign up**은 끕니다 (아무나 가입하지 못하게).
4. **Authentication → Users → Add user**로 나와 4명의 계정을 만듭니다 (*Auto Confirm User* 체크).
5. SQL Editor에서 내 계정을 관리자로 바꿉니다.
   ```sql
   update public.profiles set role = 'admin' where id = (select id from auth.users where email = '내이메일');
   update public.profiles set name = '홍길동' where id = (select id from auth.users where email = '친구이메일');
   ```
6. **Realtime → Settings**에서 **Allow public access**를 끕니다 (로그인한 사람만 접속 현황을 보게).
7. **Project Settings → API**의 Project URL과 anon public 키를 `config.js`에 넣습니다.

### 3. 배포 (Cloudflare Workers)

정적 파일과 알림 전달용 `worker.js`를 함께 배포합니다. 설정은 `wrangler.jsonc`에 있으며 빌드 단계는 없습니다.

1. `_headers`의 `YOUR-PROJECT-REF`를 본인 Supabase 프로젝트 주소로 바꿉니다.
2. 폴더에서 `npx wrangler deploy`를 실행하거나, Cloudflare 대시보드 **Workers & Pages → Create → Import a repository**로 GitHub 저장소를 연결합니다.
3. 배포 주소를 사용자들에게 보냅니다. 이후 새로 배포해도 기록은 Supabase에 있어 그대로 유지됩니다.
4. (선택) 메신저 알림을 쓰려면 VAPID 키 쌍을 만들어 공개키는 `config.js`의 `pushKey`에, 비밀키는 Supabase `push_config` 표에 넣습니다.

폰에서는 사파리 **공유 → 홈 화면에 추가**, 크롬 **앱 설치**로 앱처럼 쓸 수 있습니다.

## 문제 추가·수정

`problems.js`에 같은 형식으로 문제를 추가합니다. 각 물음은 `type`(`num`·`choice`·`essay`), 반올림 자릿수 `dp`, 정답 함수 `ans(c, p)`를 가집니다.
추가한 뒤에는 꼭 검증합니다.

1. `tools/test.html`을 로컬 서버로 열면 기본 숫자 정답과 변형 숫자 400세트의 오류 점검 결과(JSON)가 나옵니다.
2. `defaults` 부분을 `tools/js_dump.json`으로 저장하고 `python tools/verify_defaults.py tools/js_dump.json`을 실행해, 독립 계산과 일치하는지 확인합니다 (새 문제는 이 스크립트에도 계산식을 추가).

## 배포 전 확인

- **비밀번호 분실**: 로그인 화면의 '비밀번호 변경'은 현재 비밀번호를 알 때만 쓸 수 있고, 분실 시 재설정 기능은 없습니다. 관리자가 Supabase **Authentication → Users**에서 해당 사용자의 비밀번호를 바꿔 주세요.
- **공용 기기**: 로그아웃하면 그 기기에 남은 내 학습 기록 사본이 지워집니다(서버 저장이 끝난 경우).
- **저장 상태 표시**: 사이드바 아래 배지가 `서버 연결 실패`이면 서버에 저장되지 않는 상태입니다. 인터넷 연결을 확인하고 새로고침하세요.
- **출석 인증**: 카메라는 https 주소에서만 켜집니다. 실제 기기에서 한 번 촬영해 보세요.
- **테스트 페이지**: `tools/`의 테스트 페이지는 개발 PC(localhost)에서만 실행되고, 배포 주소에서는 실행되지 않습니다.
